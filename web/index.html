COMPATIBILITY

互通边界

  • UDP 独立入口基岩版默认连接 19132/UDP，不能与 Java TCP 数据流直接混用。
  • 模组限制纯服务端 Fabric/NeoForge 功能可尝试；要求客户端安装模组的内容无法翻译。
  • 账号安全Online 要求 Java 账号登录；Floodgate 仅用于你能安装对应插件/模组的后端，密钥不得泄露。
