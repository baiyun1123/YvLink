COMPATIBILITY

Crossplay limits

  • Separate UDP ingressBedrock uses UDP port 19132 by default and cannot share the Java TCP stream.
  • Mod limitationsServer-only Fabric and NeoForge mods may work; client-required mod content cannot be translated.
  • Account securityOnline mode requires a Java account. Use Floodgate only with a compatible backend plugin and keep its key secret.

SAFE BOUNDARY

Version compatibility limits

  • Backend protocol translationViaLite runs after YvLink selects a route. Clients must first complete the YvLink Java handshake.
  • No PROXY headerWhen ViaLite is enabled, set PROXY Protocol to off on every route so it receives a valid Minecraft handshake.
  • Separate responsibilitiesGeyserLite translates Bedrock to Java; ViaLite handles Java protocol differences with the backend.
